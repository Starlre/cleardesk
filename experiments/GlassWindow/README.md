# 玻璃窗口验证版

这是独立的 WPF 技术实验，不是最终应用。使用 .NET 10、非 layered WPF 窗口与独立 Windows Composition 玻璃背景层。当前构建目标为 Windows 11 22H2+、x64；背景效果依赖微软 Win2D.uwp 1.28.2 和 Microsoft.VCRTForwarders.140 1.1.0。

## 运行

从仓库根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup-sdk.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\run.ps1
```

已有 SDK 时，setup 会直接返回。SDK 放在 `.tools/dotnet/`，不注册系统环境变量；仓库中的脚本使用本地 SDK。

## 当前行为

- 后台 STA 线程扫描桌面和开始菜单，将去重后的 `.lnk` / `.url` 入口及真实图标放入独立图标池，取消原有 196 个候选限制。
- 相同目标、参数、工作目录、窗口显示方式与权限标志的普通快捷方式合并；相同 URL 合并。解析失败、安装器广告快捷方式和环境变量目标保守保留。再次导入和恢复旧排序也执行去重。
- 主面板首次启动为空；点击「添加」打开图标池，支持搜索、多选与「添加到面板」确认。取消或关闭图标池不添加图标，已添加项显示标记。
- 主面板只展示用户选择的入口，提供名称搜索、每页 28 个入口。文件导入和 Explorer 拖入先进入图标池，仍需确认添加。
- 点击入口通过 Shell 打开原始文件，保留快捷方式自带的启动语义。
- 同页拖动排序，邻近图标以 180 ms 位移动画让位；Escape 取消拖动。图标右键菜单提供前后移动和「从面板移除」，不会删除源文件或快捷方式。
- Dock 最多显示 8 个入口，设置可选固定排序（默认主面板前 8 项）或最近使用（最近从澄桌成功启动的应用优先），立即生效并保存；尚未实现独立固定项。
- 拖动 Dock 空白处或按住左侧九宫格按钮可移动位置；九宫格单击仍切换主面板，超过系统拖动距离后移动 Dock，松开不切换面板。拖动右侧把手可整体放大、缩小。右键菜单和 Ctrl + 滚轮也可调整大小，菜单提供左下、底部中央与右下位置预设。
- 右上角「设置」提供 0%–100% 透明度滑动条及百分比显示，实时同步主面板与 Dock 的玻璃底色，图标和文字保持清晰；下次启动沿用上一次透明度。高级选项保留玻璃/实色、圆角和窗口诊断。
- 默认采用半透明玻璃着色和轻微高光，启动器的可见边界与实际窗口均为 32 DIP 四角圆角；Dock 使用 40 DIP 圆角。原生裁切默认开启。
- 澄桌常驻系统托盘，主面板、Dock、图标池和窗口验证页不显示任务栏按钮。点击托盘图标可恢复面板与 Dock，右键菜单提供显示、隐藏全部窗口与退出操作。
- 右上角横线按钮仅隐藏主面板、设置/图标池及主面板玻璃，Dock 保持显示，九宫格可恢复。Escape、关闭与托盘隐藏命令隐藏全部窗口；托盘恢复后排序保持不变。
- 右上角关闭按钮和 Alt+F4 隐藏全部窗口，软件继续后台运行；彻底退出请使用托盘菜单「退出澄桌」。
- 托盘图标使用固定标识，在 Explorer 重启后重新注册；退出时删除图标并释放资源。是否折叠到通知区域「^」由 Windows 的托盘显示设置决定。
- 同用户同会话只保留一个澄桌实例，重复启动恢复已有窗口；运行脚本发现已有实例时跳过构建。托盘临时不可用时保留界面并重试注册，避免重复启动争用托盘标识导致启动失败。

手动选择的入口与排序保存在 `artifacts/GlassWindow/panel-state.json`，下次启动仅恢复这些入口。旧版自动填充生成的 `state.json` 原样保留，不自动迁移到新面板。未确认的外部文件候选仅在当前会话的图标池中保留；确认添加后可在下次启动恢复。此 JSON 仅为实验数据；正式应用仍计划使用 SQLite。

Dock 位置与缩放比例保存在 `artifacts/GlassWindow/dock-layout.json`。默认大小为 620 × 88 DIP，缩放范围为 65%–160%，上限同时受主屏工作区域宽度限制；移动时保持 Dock 在主屏工作区域内。当前尚未支持跨屏摆放。

透明度保存在 `artifacts/GlassWindow/appearance-settings.json`，首次默认 72%，拖动停止后自动保存，关闭设置或退出时补充保存。启动时先读取已保存值，再显示玻璃窗口；主题切换、隐藏及恢复不会重置透明度。实色模式和系统透明效果不可用时保持实色背景，保留用户透明度偏好。

Dock 排序方式与最近使用记录保存在 `artifacts/GlassWindow/dock-preferences.json`。只记录从澄桌成功启动的入口，固定模式下也保留记录，最近模式下未使用项按主面板顺序补齐。切换排序不改变主面板顺序，历史不会恢复已移除的应用。

## 自动验证

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run.ps1 -Verify
```

验证会短暂显示自有背景窗口、面板和 Dock，记录 Shell 图标、合成层、焦点、搜索、分页、排序/取消、重复导入与保存恢复，并截图后自动退出。四角检查会比较窗口显示和隐藏时的实际背景像素，并临时恢复矩形系统背景，确认能检测旧问题。输出在 `artifacts/GlassWindow/verification/`。

需要检查真实鼠标事件链时运行 `scripts/run.ps1 -Verify -InputTest`。该模式会短暂在验证窗口内移动鼠标，检查释放排序、Escape 取消、Dock 移动与把手缩放，然后恢复鼠标位置；全部外部启动请求被拦截。普通 `-Verify` 不模拟鼠标输入。

接口成功、截图生成与模型验证不能替代真实鼠标拖动、阴影比较、系统透明开关、动态背景、混合 DPI 和多屏人工验证。当前不支持 AppsFolder 虚拟入口、跨页拖动、自动隐藏、运行状态或独立 Dock 固定配置。
