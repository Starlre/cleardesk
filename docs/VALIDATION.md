# 技术验证与验收

更新日期：2026-10-12。V1 已完成部分检查与本机截图审阅，最新启动与显隐结果见 [验证记录](evidence/2026-10-12-startup-and-minimize.md)。各轮证据保留当时行为，当前功能以 [使用说明](FEATURES.md) 为准。

已验证图标池空面板、候选去重、手选确认、同页排序、托盘显隐清理、Dock 按钮与空白拖动、缩放、透明度保存及单实例唤回。其余场景仍需继续验证，接口成功不代表完整视觉与系统验收。

## V1：玻璃窗口

实验目录：`experiments/GlassWindow`。优先级：最高。

当前使用非 layered WPF 前景与独立 Windows Composition 圆角模糊层；原 DWM Acrylic 矩形背景已禁用。检查普通面板与 Dock 两种形状，记录背景材质、圆角裁切、阴影与命中区域之间的限制。

| 场景 | 预期 |
| --- | --- |
| 背后是壁纸、普通窗口与动态内容 | 记录真实材质表现，区分 Acrylic、Mica 和纯半透明 |
| 浅色/深色主题及活动/非活动窗口 | 文本清晰，材质变化符合预期 |
| 系统透明效果关闭 | 外观按明确策略降级，仍可使用 |
| 大圆角面板和胶囊 Dock | 裁切与边界一致，阴影无明显异常 |
| 圆角外部及透明区域点击 | 下方窗口可按设计交互，无多余阻挡区域 |
| Dock 悬停、启动器搜索 | Dock 不主动抢焦点，启动器可正常输入 |
| 不同缩放与窗口尺寸 | 轮廓、阴影、图标和命中区域一致 |

通过条件：产品要求的材质、形状、命中与焦点同时成立；不支持的场景有经过检查的降级外观。如果未通过，补充 WinUI 3 最小实验后更新 ADR，不仅凭截图切换框架。

## V2：Shell 链路

实验目录：`experiments/ShellIntegration`。
当前入口链路已在 `experiments/GlassWindow/CatalogService.cs` 原型实现，尚未提取到独立实验或正式服务。

| 样例 | 检查内容 |
| --- | --- |
| 普通 `.lnk` | 名称、图标、原始路径与启动行为 |
| 带参数和工作目录的 `.lnk` | 参数与目录语义保留 |
| `.url` 与 Steam 协议链接 | 按协议处理器启动 |
| 普通文件与文件夹 | 文件关联和目录打开正确 |
| 打包应用 | AppsFolder 枚举、AUMID、图标和激活 |
| 失效快捷方式、损坏图标或不可访问路径 | 后台处理失败，界面保持可用 |
| 从 Explorer/桌面拖入 | 文件路径数据正常导入，取消无副作用 |
| Shell 虚拟项目拖入 | 单独确认支持范围，不能假设都包含磁盘路径 |

通过条件：每种声称支持的入口均有可复现样例；启动行为、错误反馈与缓存行为可确认。需要权限提升的目标交给系统正常提示流程处理。

当前 Dock 交互在 `experiments/GlassWindow` 验证，独立目录仍为骨架。

- [x] Dock 空白与九宫格真实鼠标移动不抢焦点、不误启动；九宫格单击切换面板。
- [x] 把手真实鼠标放大缩小，图标与玻璃边界同步，位置与比例保存恢复。
- [x] 面板最小化保留 Dock，九宫格恢复位置、背景与入口顺序。
- [x] 关闭/隐藏保持托盘可恢复，重复启动通过单实例显示事件复用现有窗口。

- [ ] 当前应用中输入文字时，Dock 悬停/显现不改变输入焦点。
- [ ] 点击入口可启动目标；已有窗口的切换结果可确认。
- [ ] 一个应用有多个窗口时，可选择目标窗口。

- [ ] 前台权限限制时，有明确的失败或替代反馈。
- [ ] 全屏应用场景下，Dock 的显隐和层级符合所选策略。

## 核心功能验收

- 首次空面板、独立图标池、多选确认与取消，以及移除不删除源文件已有自动检查。
- 透明度实时调整、重开设置不重置、主题变化保留值与配置加载已有检查。
- 同页、跨页与跨区域拖动分别记录结果；释放后保存，取消后恢复。
- 拖动快速反向时没有明显跳变；减少动画设置生效。
- 搜索不改变原始排序，键盘可完成选择和启动。
- 重启程序后入口、Dock 顺序和设置一致。
- 导入重复项、目标移动或删除时有明确处理结果。
- 数据迁移失败后保留可恢复的旧数据。
