# 产品范围与交互

## 目标

提供一个常驻 Windows 桌面的应用启动器和浮动 Dock。用户可以集中管理启动入口、快速查找应用，并通过拖动整理图标。

参考方向为用户提供的截图：深色半透明玻璃面板、圆角 Dock、网格图标、分页，以及拖动时邻近图标自然让位。截图目前仅存在于会话中，仓库中尚未保存参考图片。

## 首发范围

当前可用功能与操作以 [FEATURES.md](FEATURES.md) 为准。以下表格是正式 MVP 目标，独立 Dock 固定项、SQLite、全局快捷键和开机启动尚未实现。

| 能力 | MVP 行为 |
| --- | --- |
| 启动器 | 独立浮动窗口，显示应用网格，支持分页 |
| 搜索 | 按显示名称过滤，支持键盘选择和启动；拼音搜索后续评估 |
| 添加 | 从桌面/开始菜单导入；支持文件选择和拖入 `.lnk`、`.url`、文件、文件夹 |
| 启动 | 按原有快捷方式、协议或文件关联启动目标 |
| 排序 | 网格内部拖动排序，其他图标平滑让位 |
| Dock | 固定常用入口，点击启动，提供打开启动器的入口 |
| 设置 | 图标大小、主题、材质强度、全局快捷键、可选开机启动 |
| 持久化 | 保存启动入口、排序、Dock 项和设置；重启后恢复 |

打包应用的枚举与启动在 Shell 验证阶段确认，再确定 MVP 覆盖范围。未经验证的入口不能标为完整支持。

## 交互约定

### 启动器

- 打开后可获取键盘焦点并使用搜索；非排序状态 Escape 隐藏全部窗口，横线最小化只隐藏面板、保留 Dock。
- 点击外部关闭时，不影响当前应用的工作状态。
- 搜索结果是临时视图，首版不允许在搜索结果中拖动改变原始排序。
- 分页布局使用 DIP 逻辑尺寸，按窗口宽高计算网格容量。
- 提供明确的编辑入口，避免用户误把图标拖动当成窗口拖动。

### 拖动排序

1. 指针超过系统拖动阈值后开始拖动，普通点击仍用于启动。
2. 被拖条目显示浮层，原位置保留占位。
3. 根据指针所在区域计算候选插入位，邻近图标使用位移动画让位。
4. 释放后完成吸附，并一次性保存顺序；Escape 或取消恢复原顺序。
5. 第一轮仅实现同页排序，后续再增加跨页和拖入 Dock。

让位动画从 120–220 ms 范围开始调试。快速反向拖动时，从当前视觉位置继续动画，避免图标跳回旧位置。保留菜单或键盘调整顺序的方式，并支持减少动画。

### Dock

- 悬停和自动显现不主动抢占输入焦点。
- 当前显示启动器前 8 个入口；独立固定入口与顺序是后续目标。
- 九宫格单击切换面板，按住拖动移动 Dock；空白处也可移动，右侧把手、Ctrl + 滚轮与菜单调整大小。
- 位置、大小和透明度保存，下一次启动沿用用户配置。
- 图标移除动作删除应用内的条目或固定关系，不删除磁盘文件。
- 运行状态与已有窗口切换作为后续增强，支持多个窗口时需提供选择入口。
- 自动隐藏在基本点击与焦点行为稳定后实现。

## 视觉与性能方向

- 采用系统背景材质，UI 层叠加半透明着色、细边框和适量高光。
- 深浅主题分别检查文字、焦点框和图标标签的可读性；背景过于复杂时提高面板着色强度。
- 材质不可用时提供半透明或实色呈现，并记录具体降级条件。
- 动画目标为 60 fps，使用实际硬件测量帧时间；当前尚无性能实测。
- 应用索引与图标提取在后台执行；常驻空闲时避免持续高频刷新。

## 后续能力

运行中窗口归组、自动隐藏、多屏独立布局、分组、配置导入导出、更新机制，以及需要时的 Windows 10 兼容。

系统桌面分区、Explorer 图标接管和 WorkerW 嵌入属于独立扩展范围，不作为当前架构的基础依赖。
