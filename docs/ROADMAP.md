## P1：技术验证

依赖：SDK 就绪。

- [ ] V1：WPF 原生窗口、Desktop Acrylic、圆角、阴影、命中和焦点。
- [ ] V2：快捷方式/协议/文件夹的枚举、图标、拖入与启动。
- [ ] V3：Dock 不抢焦点、激活窗口、显隐和全屏场景。
- [ ] V4：混合 DPI、多屏、Explorer 重启与休眠恢复。
- [ ] 提交验证证据，确认 WPF 或调整 ADR。

阶段交付：可重复运行的最小实验和验证记录。视觉要求与命中区域不能同时成立时，不进入整套 UI 开发。

## P2：功能骨架

依赖：核心窗口与 Shell 路线确认。

- [ ] 创建正式解决方案、App、Core、Infrastructure 项目。
- [ ] 建立启动入口模型和完整启动描述。
- [ ] 实现桌面/开始菜单导入、图标后台读取与缓存。
- [ ] 实现 SQLite 初始结构、迁移和配置恢复。
- [ ] 实现按显示名称搜索及基础应用启动。

阶段交付：真实入口可导入、可查找、可启动，重启后数据保持完整。

## P3：核心交互

- [ ] 启动器网格、窗口尺寸适配和分页。
- [ ] 同页拖动排序、让位动画、吸附和取消。
- [ ] 固定 Dock 项与独立顺序。
- [ ] 跨页拖动与拖入 Dock。
- [ ] 键盘操作、菜单调整顺序与减少动画。
- [ ] 深浅主题、文字可读性、焦点反馈和材质降级。

阶段交付：用户可整理入口并从启动器或 Dock 快速启动，排序保存可靠。

## P4：桌面集成完善

- [ ] 运行状态归组与已有窗口选择/切换。
- [ ] 全局快捷键、托盘和可选开机启动。
- [ ] Dock 自动隐藏和全屏场景策略。
- [ ] 多屏、主屏切换、显示器拔插和混合缩放。
- [ ] Explorer 重启与休眠恢复。
- [ ] 记录常驻内存、空闲 CPU、打开面板耗时和拖动帧时间。

阶段交付：典型桌面使用场景稳定，性能结果有硬件与场景说明。

## P5：发布准备

- [ ] 确定安装方式并验证安装、升级与卸载。
- [ ] 配置导入导出、日志轮转与故障定位。
- [ ] 数据升级前备份和迁移失败恢复。
- [ ] 制定版本号、更新策略、签名与分发方式。
- [ ] 完成发行版人工验证并记录已知限制。
