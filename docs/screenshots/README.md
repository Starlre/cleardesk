# 澄桌完整桌面截图

拍摄日期：2026-10-12。环境：Windows 11 `10.0.22631.0`、x64、150% 缩放；主屏原始分辨率 2560 × 1600。

全部图片来自正在运行的澄桌普通实例，保留整张主屏、真实壁纸和 Windows 任务栏，没有使用验证背景或裁切窗口。图中的 21 个应用是手动添加的示例；首次启动主面板为空，Dock 只显示左侧九宫格。壁纸和桌面时钟来自现有桌面，属于拍摄背景。

拍摄时将 Dock 临时放到任务栏上方，分别展示 72% 与 100% 透明度、图标池、设置和面板最小化。没有添加/移除应用，没有修改 Dock 排序或桌面图标开关；结束后恢复拍摄前的透明度、Dock 位置与面板显示状态。

## 磨砂面板与 Dock

72% 透明度，壁纸在面板内部产生模糊，圆角内侧切面高光可见，图标和文字保持清晰。

![72% 透明度的完整桌面实拍](desktop-frosted.png)

## 清透面板与 Dock

100% 透明度，底色透明、背景模糊降到接近清透。与上一张使用同一壁纸，便于比较。

![100% 透明度的完整桌面实拍](desktop-clear.png)

## 图标池

搜索 Adobe 后显示候选入口，已添加项有状态标记；只有确认选择后才加入主面板。

![图标池搜索的完整桌面实拍](desktop-icon-pool.png)

## 设置

透明度、Dock 固定/最近使用排序和「隐藏 Windows 桌面图标」位于同一设置页。截图时系统桌面图标已隐藏，澄桌入口仍可见。

![设置页面的完整桌面实拍](desktop-settings.png)

## 最小化保留 Dock

主面板收起后，Dock 继续显示；它位于 Windows 任务栏上方，左侧九宫格可恢复面板。

![最小化面板后保留 Dock 的完整桌面实拍](desktop-dock.png)
