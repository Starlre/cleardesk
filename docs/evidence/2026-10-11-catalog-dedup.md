# 应用重复入口修复验证

日期：2026-10-11。环境：Windows 11 `10.0.22631.0`、.NET SDK 10.0.401、运行时 10.0.12、x64、窗口 DPI 144。

## 原因与修复

原索引仅按 `.lnk` 文件路径去重。阿里云盘、百度网盘、哔哩哔哩、大工程师和大国工匠在本机桌面与开始菜单存在不同路径的快捷方式，但各应用对应的启动目标、参数与工作目录一致。

新增只读 Shell Link 解析，不调用 Resolve、不改写用户快捷方式。身份包含规范化目标路径、原始参数、规范化工作目录、管理员/兼容标志及窗口显示方式。保留原快捷方式启动；不同参数、工作目录或权限不合并。相同 URL 合并，但保留路径及查询参数大小写。解析失败、非文件系统目标、安装器广告快捷方式和环境变量目标保守按来源路径区分。

扫描去重后再截取 196 个入口，保留所有合并来源路径用于旧排序匹配；导入与最终状态恢复使用同一身份规则。无需手动删除快捷方式或清空排序文件。
