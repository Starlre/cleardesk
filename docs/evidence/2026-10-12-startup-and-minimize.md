# 重复启动与最小化验证

日期：2026-10-12。环境：Windows 11 `10.0.22631.0`、.NET SDK 10.0.401、运行时 10.0.12、x64、窗口 DPI 144。

## 修复行为

旧版在已有实例后台运行时，第二次启动仍会创建窗口并注册固定托盘 GUID。用户遇到的错误为「无法创建系统托盘图标，请重新启动澄桌」，后台检查确认已有澄桌实例。

增加每用户、每会话单实例保护，重复启动通过命名事件恢复已有窗口，第二进程正常退出。启动脚本检测已有实例时跳过构建，避免占用中的 exe 无法覆盖。托盘首次注册暂时失败时保留窗口并重试注册，托盘不可用时禁止隐藏全部窗口。

按最新交互要求，横线按钮与原生最小化仅收起主面板及其设置/图标池，保留 Dock 与 Dock 玻璃；九宫格可恢复。关闭、Alt+F4、Escape 和托盘隐藏命令仍隐藏全部窗口。

## 验证结果

执行 `scripts/build.ps1` 与 `scripts/run.ps1 -Verify -InputTest -NoBuild`。Release x64 构建 0 个错误、0 个警告，119 项检查通过，进程正常退出。

- 用隔离名称取得单实例锁，实际启动第二进程，退出码为 0；已有实例通过 UI Dispatcher 收到恢复事件；释放锁后可重新取得。
- 真实 Shell 接受验证托盘注册，显示、隐藏、关闭恢复与退出清理检查通过。
- 横线按钮隐藏主面板与主玻璃，Dock 及其玻璃保持可见；九宫格恢复主面板原有位置和入口排序。
- 原生最小化同样保留 Dock，九宫格恢复后玻璃与窗口位置正确。
- 实际鼠标排序/取消、空白及九宫格拖动、缩放、单击抖动、透明度与设置保存等既有检查通过。
- 日常模式启动后重复运行 `scripts/run.ps1`，脚本跳过构建，第二进程正常退出，原 PID 保留且常驻实例数量为 1。

验证不会启动外部应用，不写用户面板选择、Dock 布局或透明度。未重启 Explorer 或关闭系统透明开关；托盘临时失败重试路径仍需在实际 Shell 故障场景复核。
