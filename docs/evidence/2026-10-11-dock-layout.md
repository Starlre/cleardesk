# Dock 显隐、移动与缩放验证

日期：2026-10-11。环境：Windows 11 `10.0.22631.0`、.NET SDK 10.0.401、运行时 10.0.12、x64、窗口 DPI 144。

## 操作

- 最小化按钮和非排序状态下的 Escape 隐藏主面板、Dock 及玻璃背景，澄桌继续驻留托盘；点击托盘图标恢复。
- 拖动 Dock 空白区域移动，拖动右侧把手放大或缩小；Ctrl + 滚轮及右键菜单也可调整大小。
- 右键提供默认大小、左下、底部中央和右下位置预设。
- Dock 整体缩放，默认 620 × 88 DIP，比例 65%–160%；上限同时受主屏宽度限制。位置限制在主屏工作区域内，当前不支持跨屏摆放。
- `artifacts/GlassWindow/dock-layout.json` 保存位置与比例，下次启动恢复。用户的应用选择与排序继续由独立面板状态保存。

## 结果

执行 `scripts/build.ps1` 和 `scripts/run.ps1 -Verify -InputTest -NoBuild`。Release x64 构建 0 个错误、0 个警告；99 项检查通过，验证进程正常退出。

- 最小化按钮同时隐藏主面板、Dock 和两个原生玻璃 HWND；托盘保持注册，恢复后主面板位置及应用顺序不变。
- 原生最小化时，打开的图标池与玻璃同步隐藏，托盘恢复后保留未确认选择。
- 右键放大缩小、最大最小比例、屏外位置限制、JSON 保存与重建恢复、损坏文件及写入失败处理通过。
- 实际鼠标拖动空白区域改变 Dock 位置，向右拖把手放大，向左拖回恢复原大小；均不抢前台焦点、不触发应用启动。
- 缩放后原生 UI 与玻璃窗口边界一致；复核放大、缩小截图，图标与玻璃一起缩放。
- 原有去重、图标池、排序与取消、托盘清理以及深浅主题玻璃检查通过。

验证采用临时托盘标识和隔离布局文件，不修改用户已选应用、Dock 配置，也不启动外部应用；结束时恢复鼠标。尚未验证多屏或混合 DPI。
