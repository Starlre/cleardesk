# 透明度设置验证

日期：2026-10-11。环境：Windows 11 `10.0.22631.0`、.NET SDK 10.0.401、运行时 10.0.12、x64、窗口 DPI 144。

右上角「设置」提供透明度滑动条，范围 0%–100%，显示当前百分比，支持鼠标和键盘。主面板与 Dock 使用共享玻璃底色，文字和图标不参与透明度变化；玻璃模糊保留。

最后设置的透明度保存到 `artifacts/GlassWindow/appearance-settings.json`，启动显示窗口前读取，避免每次重置为默认值。350 ms 防抖保存，关闭设置或退出时补充保存。首次启动默认 72%；配置损坏时使用默认值并保留可用界面。

## 验证结果

执行 `scripts/build.ps1` 与 `scripts/run.ps1 -Verify -NoBuild`。Release x64 构建 0 个错误、0 个警告，106 项检查通过，验证进程正常退出。

- 设置按钮打开无任务栏入口的设置窗口，滑动条初始值与当前透明度一致。
- 通过真实 Slider 的可访问 RangeValue 接口调整到 20% 和 80%，共享底色 alpha 分别为 204 和 51，百分比同步变化；主面板与 Dock 整体不透明度保持 1。
- 隐藏到托盘、恢复及重新打开设置均保留已选透明度；设置窗口随主面板隐藏。
- 主题变化不覆盖透明度，实色降级保持 alpha 255，同时保留已选透明度偏好。
- 配置原子保存后加载得到上一次值，损坏 JSON 安全回退，超范围值限制到合法范围，保存失败可反馈。
- 原有图标池、去重、Dock 布局、排序、托盘清理与深浅主题背景检查通过。
- 复核 150% DPI 下的设置截图，滑动条、百分比、说明与高级选项显示完整。

验证采用隔离状态，不改变用户选择与外观配置，不启动外部应用。本轮未注入鼠标；Dock 鼠标移动与缩放验证见上一轮记录。
