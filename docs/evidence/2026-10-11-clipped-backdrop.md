# 玻璃背景圆角裁切验证

此前设置圆角窗口区域后，系统背景材质仍填满外接矩形，导致圆弧外留下玻璃区域。原生区域检查只能证明命中区域正确，不能证明背景材质已经裁切。

当前关闭矩形系统背景，使用独立、无激活的 Windows Composition 窗口承载背景采样与 Gaussian blur。背景视觉通过圆角几何裁切，位于清晰的 WPF 前景后方；两层同步位置、显隐和窗口顺序。启动器圆角为 32 DIP，Dock 为 40 DIP。系统透明关闭、高对比度或合成不可用时使用实色降级。

本机 Windows 11 构建 22631、150% 缩放。Release x64 构建为 0 错误、0 警告；最终执行 `scripts/run.ps1 -Verify -InputTest -NoBuild`，46 项检查通过。

- 深浅主题中，启动器每轮比较四角外 64 个像素，Dock 比较 100 个像素；均与隐藏窗口后的背景完全一致，最大 RGB 差值为 0。
- 临时恢复矩形系统背景时，像素检查能检测残留并报错；随后恢复正确材质。
- 检查玻璃背景随前景一起隐藏、移动后四边对齐、激活后位于前景正后方。
- 真实鼠标拖动完成排序，Escape 取消并恢复顺序；验证期间拦截外部启动请求，结束后恢复鼠标位置。
