# 系统托盘常驻验证

日期：2026-10-11。环境：Windows 11 `10.0.22631.0`、.NET SDK 10.0.401、运行时 10.0.12、x64、窗口 DPI 144。

## 行为

澄桌使用原生 `Shell_NotifyIcon` 注册蓝色九宫格托盘图标，提示文字为「澄桌（ClearDesk）」。主面板、Dock、图标池和窗口验证页均不显示任务栏按钮。

点击托盘图标恢复面板和 Dock；右键菜单提供「显示应用面板」「隐藏全部窗口」「退出澄桌」。横线按钮与 Escape 隐藏面板，保留 Dock；关闭按钮和 Alt+F4 隐藏全部窗口，继续后台运行。彻底退出需使用托盘菜单。应用未开启开机自启。

托盘图标采用固定 GUID，Explorer 重启时重新注册，暂时失败时定时重试；退出时移除图标、事件钩子与原生图标句柄。图标是否折叠至「^」由 Windows 通知区域设置决定，应用不改写用户的显示偏好。

- 通过通知消息打开右键菜单，验证菜单包含显示、隐藏和退出操作。
- 隐藏全部窗口后托盘保持注册；点击通知图标和菜单显示操作均可恢复窗口。

- 原有图标池、排序、去重、Dock 和玻璃显示验证通过。
