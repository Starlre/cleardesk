# Dock 排序选项验证

日期：2026-10-12。环境：Windows 11 `10.0.22631.0`、.NET SDK 10.0.401、运行时 10.0.12、x64、窗口 DPI 144。

「设置 → Dock 应用排序」提供固定排序与最近使用，默认固定。固定排序沿用主面板前 8 项；最近模式将通过澄桌成功启动的已选入口优先展示，未使用项按主面板顺序补齐。模式与最多 512 条最近记录写入 `dock-preferences.json`，启动恢复；面板顺序保持独立。

执行 `scripts/build.ps1` 和 `scripts/run.ps1 -Verify -NoBuild`。Release x64 构建 0 个错误、0 个警告，最终 128 项检查通过，验证进程退出码为 0。首次验证超过 60 秒被脚本终止，重跑后完整结束；以最终报告为准。

- 固定模式成功启动应用后 Dock 不移动；切换最近模式后，原本位于第 10、11 项的应用进入前列。
- 重复启动移到第一位，没有重复图标；失败启动不改变 Dock 或持久化历史。
- 最近排序不改变面板顺序，搜索不影响 Dock；移除最近应用后从 Dock 消失并补齐空位。
- 重建视图模型后模式与最近顺序保留，切回固定恢复面板顺序，再切最近保留历史。
- 损坏 JSON 回退固定，非法模式、空记录与重复记录规范化；写入失败反馈可见。
- 实际设置下拉框切换立即更新模式，重开设置保留选择；150% DPI 截图中的控件与说明显示完整。
- 原有托盘、最小化、图标池、去重、排序、透明度与玻璃检查通过。

验证使用隔离设置文件和成功/失败启动替代函数，不启动外部应用，不修改用户面板、透明度或 Dock 配置。本轮未注入鼠标，既有拖动/缩放记录保留。
