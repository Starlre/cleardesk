# 九宫格按钮拖动 Dock 验证

日期：2026-10-11。环境：Windows 11 `10.0.22631.0`、.NET SDK 10.0.401、运行时 10.0.12、x64、窗口 DPI 144。

按住左侧九宫格按钮并移动鼠标，可拖动整个 Dock，松开后保存位置。单击仍切换主面板，超过系统拖动距离后才进入拖动状态；拖动结束不会触发单击。应用图标继续点击启动，右侧把手继续用于缩放。

执行 `scripts/build.ps1` 与 `scripts/run.ps1 -Verify -InputTest -NoBuild`。Release x64 构建 0 个错误、0 个警告，114 项检查通过。

- 实际鼠标按下九宫格按钮，向左 48 px、向上 24 px 移动后释放，Dock 位置改变，主面板仍显示，前台焦点未改变，应用启动计数为 0。
- 实际鼠标单击时移动 1 px，主面板隐藏，Dock 保持显示且位置不变。
- 再次单击恢复主面板，未触发应用启动。
- 原有空白区域移动、把手放大缩小、图标排序与取消、透明度保存和托盘显隐检查通过。

验证使用隔离配置，结束后恢复鼠标与 Dock 位置，不改变用户应用选择、透明度或 Dock 配置。完整报告：[按钮拖动验证报告](dock-button-drag-report.json)。未提交或推送 Git。
