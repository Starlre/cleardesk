## 2026-10-11：修复外层小圆角

- 移除与自定义 HWND 区域竞争的 WPF WindowChrome，由单一逻辑维护窗口轮廓。
- 自定义裁切启用时禁用系统圆角与系统边框，仅保留面板自身的圆角边缘。
